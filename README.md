# hosts

Aplikasi Android untuk menjalankan server HTTP lokal dengan konfigurasi IP, DNS, rules, dan hamburger menu.

## Fitur

- Dashboard dengan status server
- Konfigurasi port dan nama server
- Konfigurasi IP lokal
- Konfigurasi DNS
- Aturan akses (rules)
- Log server
- Pengaturan (mode gelap, auto-start, notifikasi)
- Tentang dan Bantuan

## Menjalankan

1. Buka folder proyek ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Jalankan aplikasi pada emulator atau perangkat Android.
4. Buka hamburger menu untuk navigasi antar halaman.
5. Konfigurasikan IP, DNS, dan rules sesuai kebutuhan.
6. Tekan **Mulai Server** pada Dashboard atau halaman Server.
7. Buka alamat yang ditampilkan dari perangkat lain pada jaringan Wi-Fi yang sama.

## Build

Proyek menggunakan Gradle 8.5 dan Android Gradle Plugin 8.2.2 dengan AndroidX dan Material Components.
