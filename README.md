# hosts

Aplikasi Android sederhana untuk menjalankan server HTTP lokal dari perangkat.

Proyek ini menggunakan Gradle 6.0 dan Android Gradle Plugin 3.6.4.

## Menjalankan

1. Buka folder proyek ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Jalankan aplikasi pada emulator atau perangkat Android.
4. Masukkan port antara `1024` dan `65535`, lalu tekan **Mulai server**.
5. Buka alamat IP yang tampil dari perangkat lain pada jaringan Wi-Fi yang sama.

Server menyajikan halaman HTML status dan dapat dihentikan kapan saja dari aplikasi.
